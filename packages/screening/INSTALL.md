# Installing screening

Screening is prompt policy, not code. The `install_package` tool copies its
skill file verbatim (via this package's `install.sh`) — you do not retype it.

1. Run `install_package` with name `screening` (it is also pulled in
   automatically as a dependency of public-facing packages).
2. Read the installed `skills/screening/SKILL.md` once so its rules are fresh
   in this session. That is all — there is nothing to configure.
